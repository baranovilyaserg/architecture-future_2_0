Матрица рисков трансформации Future 2.0

Легенда

Вероятность: Низкая, Средняя, Высокая
Влияние: Низкое, Среднее, Высокое
Риск = Вероятность x Влияние

Архитектурные риски

Риск: Deduplication и eventual consistency в event-driven архитектуре
Вероятность: Высокая
Влияние: Среднее
Описание: При обработке одного события несколько подписчиков могут получить дубли, что приведет к некорректности отчётов и KPI
Приоритет: Высокий (3/3)

Риск: Data latency в витрине данных превышает требования бизнеса
Вероятность: Средняя
Влияние: Высокое
Описание: Event Streaming добавляет задержку, аналитики ждут часы перед получением данных
Приоритет: Высокий (2/3)

Риск: Потеря данных при сбое Event Stream
Вероятность: Средняя
Влияние: Высокое
Описание: Kafka/RabbitMQ сбой приведет к потере событий и разрыву цепи трансформации
Приоритет: Высокий (2/3)

Риск: Нарушение целостности данных при распределении по доменам
Вероятность: Средняя
Влияние: Среднее
Описание: Cross-domain transactional consistency (например, одновременный платёж и обновление витрины)
Приоритет: Средний (2/2)

Риск: Неполная миграция медицинских данных - утечка конфиденциальной информации
Вероятность: Низкая
Влияние: Высокое
Описание: Медкарты/диагнозы попадут в витрину нарушив GDPR/локальные регулятивы
Приоритет: Высокий (1/3)

Риск: Производительность витрины при масштабировании на 100+ TB
Вероятность: Средняя
Влияние: Среднее
Описание: Query performance деградирует при хранении huge объемов аналитических данных
Приоритет: Средний (2/2)

Организационные риски

Риск: Недостаток компетенций в Event Sourcing и Kafka
Вероятность: Высокая
Влияние: Высокое
Описание: Команда не имеет опыта работы с event-driven архитектурой, ошибки в проектировании событий
Приоритет: Высокий (3/3)

Риск: Сопротивление изменениям от команды DWH/PowerBuilder
Вероятность: Высокая
Влияние: Среднее
Описание: Legacy-разработчики отказываются переходить на новые технологии, замедляет миграцию
Приоритет: Высокий (3/2)

Риск: Слабое управление проектом трансформации
Вероятность: Средняя
Влияние: Высокое
Описание: Отсутствие чётких этапов и ответственности приведет к срывам сроков и бюджета
Приоритет: Высокий (2/3)

Риск: Недостаток ресурсов для параллельной поддержки Legacy и New
Вероятность: Высокая
Влияние: Среднее
Описание: Команда должна одновременно поддерживать DWH/PowerBuilder И разрабатывать новую архитектуру
Приоритет: Высокий (3/2)

Риск: Отсутствие чёткого видения доменных границ
Вероятность: Средняя
Влияние: Среднее
Описание: Неправильное decompose на домены приведет к tight coupling и нарушению целей
Приоритет: Средний (2/2)

Риск: Change fatigue в организации
Вероятность: Средняя
Влияние: Среднее
Описание: Частые изменения в архитектуре приводят к выгоранию команды и снижению качества
Приоритет: Средний (2/2)

Технологические риски

Риск: Недостаточная надёжность схемы миграции из DWH
Вероятность: Средняя
Влияние: Высокое
Описание: CDC (Change Data Capture) или ETL не корректно переносят данные в витрину
Приоритет: Высокий (2/3)

Риск: API Gateway становится bottleneck при масштабировании
Вероятность: Средняя
Влияние: Среднее
Описание: Синхронный доступ через API Gateway создаёт узкое место для витрины
Приоритет: Средний (2/2)

Риск: Несовместимость версий Kafka/RabbitMQ при апдейте
Вероятность: Низкая
Влияние: Высокое
Описание: Breaking changes в версии месседжера приводят к сбою всех интеграций
Приоритет: Средний (1/3)

Риск: Отсутствие мониторинга и алертов для Event Stream
Вероятность: Средняя
Влияние: Среднее
Описание: Потерянные события или задержки не обнаруживаются вовремя
Приоритет: Средний (2/2)

Риск: Security уязвимости в Event Stream (MiTM, неавторизованный доступ)
Вероятность: Низкая
Влияние: Высокое
Описание: Без SSL/TLS и авторизации события могут быть перехвачены/модифицированы
Приоритет: Средний (1/3)

Риск: Нарушение compliance требований финансовых регуляторов
Вероятность: Средняя
Влияние: Высокое
Описание: Event-driven архитектура требует других подходов к аудиту и тревейсингу
Приоритет: Высокий (2/3)

Финансовые риски

Риск: Перерасход бюджета на инфраструктуру
Вероятность: Средняя
Влияние: Среднее
Описание: Облачные сервисы дороже чем ожидалось (Kafka, Stream Processing, Витрина)
Приоритет: Средний (2/2)

Риск: Переоценка ROI самообслуживаемой витрины
Вероятность: Средняя
Влияние: Среднее
Описание: Витрина требует обучения пользователей, не все смогут её использовать
Приоритет: Средний (2/2)

1. Deduplication и eventual consistency (3x3)
2. Недостаток компетенций Event Sourcing (3x3)
3. Сопротивление изменениям Legacy-команды (3x2)
4. Data latency в витрине (2x3)
5. Потеря данных в Event Stream (2x3)
6. Недостаток ресурсов Legacy+New (3x2)
7. Слабое управление проектом (2x3)
8. Нарушение compliance финансовых регуляторов (2x3)

Средний приоритет:
9. Недостаточная надёжность миграции (2x3)
10. API Gateway bottleneck (2x2)
11. Отсутствие мониторинга Event Stream (2x2)
12. Нарушение целостности cross-domain (2x2)
13. Performance витрины (2x2)
14. Неполная миграция медицинских данных (1x3)
15. Отсутствие доменных границ (2x2)
16. Change fatigue (2x2)
17. Перерасход инфраструктуры (2x2)
18. Переоценка ROI витрины (2x2)

Низкий приоритет:
19. Несовместимость версий Kafka (1x3)
20. Security уязвимости Event Stream (1x3)
